## 🚀 Projetos em destaque · Featured projects

### 🎯 [Programando o Futuro](https://github.com/vic-cavalcant3/Programando-o-Futuro) · *em equipe / team project*
🇧🇷 Plataforma web que usa a **Claude API** para gerar planos de carreira personalizados para estudantes de escola pública. Foi validada com 31 alunos de uma escola estadual. Minha parte: **tratamento de erros da API de IA** (HTTP 429 e 529, com novas tentativas) e um **script de teste de carga** que simula usuários simultâneos. Depois das correções, 15 usuários ao mesmo tempo foram atendidos sem falhas.<br/>
🇺🇸 *Web platform that uses the **Claude API** to build personalized career plans for public school students, tested with 31 students. My part: **AI API error handling** (HTTP 429/529 with retries) and a **load-testing script**; after the fixes, 15 concurrent users ran with no failures.*<br/>
`Python` `FastAPI` `MySQL` `Claude API` `Render`

### ✅ [TaskFlow — Gerenciador de Tarefas](https://github.com/yagodias-dev/gerenciador-tarefas)
🇧🇷 API REST de tarefas com **Java 17 e Spring Boot**, persistência com JPA/Hibernate em **PostgreSQL (Supabase)**, back-end em container **Docker** no Render e front-end na Vercel.<br/>
🇺🇸 *Task management REST API built with **Java 17 + Spring Boot**, JPA/Hibernate on **PostgreSQL (Supabase)**, **Dockerized** back-end on Render and front-end on Vercel.*<br/>
`Java` `Spring Boot` `JPA` `PostgreSQL` `Docker`

### ⚙️ [fastapi-docker-ci](https://github.com/yagodias-dev/fastapi-docker-ci)
🇧🇷 API em **FastAPI** com testes, **Docker** e pipeline de CI/CD no **GitHub Actions**, com aprovação manual antes de produção.<br/>
🇺🇸 ***FastAPI** service with tests, **Docker** and a **GitHub Actions** CI/CD pipeline with manual approval before production.*<br/>
`Python` `FastAPI` `Docker` `GitHub Actions`

### 🏭 [SMART 4.0 · Console de Expedição & OEE](https://github.com/yagodias-dev/expedicao) · *em equipe / team project*
🇧🇷 Micro-frontend de uma planta industrial simulada: recebe telemetria por **WebSocket**, calcula o **OEE** (disponibilidade × performance × qualidade) e mostra gráficos e ordens de produção. Tem testes com Vitest e deploy automático na Vercel.<br/>
🇺🇸 *Micro-frontend for a simulated factory line: consumes **WebSocket** telemetry, computes **OEE** and shows charts and production orders. Unit tests with Vitest and automatic deploy to Vercel.*<br/>
`React` `TypeScript` `Vite` `Tailwind` `Recharts` `Vitest`

### 📡 [NOC Command Center](https://github.com/yagodias-dev/noc-command-center)
🇧🇷 Refatoração de um painel de monitoramento que era um único arquivo HTML para uma arquitetura em **componentes React + TypeScript**, com a regra de negócio centralizada em hooks.<br/>
🇺🇸 *Refactor of a single-file HTML monitoring dashboard into a **React + TypeScript** component architecture, with business logic centralized in hooks.*<br/>
